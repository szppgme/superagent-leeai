# superagent-leeai

superagent-leeai 是一个用于试验和演示 superagent 智能体工作流的示例项目。

## 用法

克隆仓库到本地：

```bash
git clone https://github.com/szppgme/superagent-leeai.git
cd superagent-leeai
```

## 开发

需要 Python 3.10 或更高版本。

安装测试依赖：

```bash
python -m pip install pytest==7.4.4
```

在仓库根目录运行测试：

```bash
python -m pytest
```
